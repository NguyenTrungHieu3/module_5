React Element ,cơ chế Rendering Elements Giới thiệu Trong React, Element là những mảnh ghép nhỏ nhất của các ứng dụng React. Không giống như những element DOM của trình duyệt, React element là những “đối tượng đơn giản” (plain object) và rất dễ để tạo ra. React DOM giữ vai trò cập nhật DOM để phù hợp với các React element.

React Element là gì? React element chỉ là một đối tượng JavaScript cũ đơn thuần mà không có các phương thức riêng, là những gì được trả về từ các components. Nó mô tả những gì chúng ta muốn thấy trên màn hình, nó là thành phần đại diện của DOM Với function component, element là đối tượng mà hàm trả về Với class component, là đối tượng mà hàm render của thành phần đó trả về

React Element là gì? React.createElement có cú pháp sau: React.createElement(type, [props], [...children]) type có thể là một thẻ HTML như h1, div hoặc nó có thể là React component prop là các thuộc tính bạn muốn phần tử có children chứa các thẻ HTML khác hoặc có thể là component

Rendering Elements trong DOM Để render một phần tử React vào root DOM, thì ta dùng phương thức ReactDOM.render() Cú pháp : ReactDOM.render(element, container[, callback])

---PAGE---
Rendering Elements trong DOM Phương thức sẽ render phần tử React vào DOM trong vùng chứa được cung cấp và trả về một tham chiếu đến thành phần (hoặc trả về null cho các thành phần không trạng thái). Nếu phần tử React trước đó đã được hiển thị vào vùng chứa, thì phần tử này sẽ thực hiện cập nhật nó và chỉ thay đổi DOM khi cần thiết để phản ánh phần tử React mới nhất. Nếu lệnh gọi lại tùy chọn được cung cấp, nó sẽ được thực thi sau khi thành phần được hiển thị hoặc cập nhật.

---PAGE---
Rendering Elements trong DOM Ví dụ: const items = [&quot;C++&quot;,&quot;PHP&quot;,&quot;JAVA&quot;]; const programming = React.createElement(&quot;section&quot;, {id: &quot;coding&quot;}, React.createElement(&quot;h1&quot;, null, &quot;Programming Languages&quot;), React.createElement(&quot;ul&quot;, {className: &quot;coding&quot;}, items.map((coding, i) =&gt; React.createElement(&quot;li&quot;, { key: i }, coding), ); ReactDOM.render(programming,document.getElementById('root') );
